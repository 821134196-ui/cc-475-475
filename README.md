# 写字楼公共冰箱格位与过期清理系统

面向写字楼共享冰箱的格位管理与过期清理系统：楼层冰箱登记、层架格位、租户部门、
物品标签、存放日期、保留期限、温度记录、临时停机、清理批次、认领申诉与卫生检查。

## 一条命令本地启动

```bash
python3 run.py          # → http://127.0.0.1:8000
```

首次启动自动建库并写入示例数据（人员与物品均为示例），内置三类演示样例：

- **无标签样例**：F12-A 的 A-1 格发现无标签饭盒（异常登记，见「物业运维」）
- **停机样例**：F15-B 压缩机故障停机，2 件未到期物品等待批量迁移
- **申诉样例**：财务部的「鲜榨果汁」已被收入临时保留区，员工申诉待复核

数据全部落在 `./data/`：SQLite（`fridge.db`，物品事件流水）+ 标签 SVG 与清理照片
（`files/labels/`、`files/photos/`）。删除该目录即可重置演示。

## 角色与分工

| 角色 | 职责 |
|---|---|
| 员工 | 贴签 → 选格 → 关门确认（三步存放），取回/申诉本部门物品 |
| 保洁 | 只能执行清理：建批次、拍照收入保留区、申诉期结束后处置 |
| 租户管理员 | 复核本部门的认领申诉（批准返还 / 驳回） |
| 物业 | 停机与批量迁移、异常处理、卫生检查、温度巡检 |

页面右上角切换身份体验不同角色（演示环境以 `X-User-Id` 请求头标识身份）。

## 核心规则

- **一格一物**：`items(slot_id)` 上的部分唯一索引保证一个格位同一时刻只有一件
  有效物品（待确认/在架/已到期未收走），并发存放仅首个事务成功，其余收到
  `slot_occupied`。
- **三步存放**：打印标签（生成 SVG 到本地目录）→ 选空余格位（暂存 120s，超时
  自动释放并恢复标签）→ 门磁闭合后确认才计入在架；每步均可撤销并有明确反馈。
- **到期清理**：进程内后台任务（默认 5s 一轮）把 `expires_at <= now` 的物品送入
  待清理收件箱；保洁拍照后物品进入临时保留区并开始申诉期倒计时（默认 48h，
  `FRIDGE_APPEAL_SECONDS` 可调）；申诉期结束且无未决申诉方可处置。
- **停机迁移**：物业停机后可把未到期物品批量迁入其他冰箱，**保留原标签码**；
  目标格位不足时剩余物品登记为「迁移缺件」异常。
- **异常分类处理**：无标签物品、占错格位、液体泄漏（自动封锁格位）、重复扫码、
  温度超限（自动告警/恢复）、迁移缺件、清理申诉。
- **租户隔离**：员工/租户管理员仅见本部门物品与申诉；格位图只暴露部门简称与日期。

## 测试

```bash
python3 -m pytest tests/ -q
```

覆盖：格位竞争（双线程同格仅首个成功）、标签失效（作废/重复扫码）、迁移完整
（未到期全量迁走且保留标签、缺件登记）、期限边界（到期瞬间、申诉窗口开关、
处置时点）、租户隔离（越权复核 403、部门数据分域）及 API 冒烟。

## 目录结构

```
run.py                 # 启动入口
fridge/
  db.py                # SQLite schema 与事务助手
  services.py          # 领域服务（存放/清理/申诉/迁移/异常/温度/卫生）
  adapters.py          # 模拟门磁与温度传感器（可替换真实硬件）
  tasks.py             # 进程内后台任务：到期扫描/暂存超时/温度巡检
  seed.py              # 示例数据（含无标签、停机、申诉样例）
  app.py               # FastAPI 接口层（角色守卫 + 租户隔离）
  static/              # 前端 SPA（办公白 / 薄荷绿 / 深灰）
tests/                 # pytest 测试
data/                  # 运行时生成：SQLite + 标签/照片文件
```

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | 8000 | 服务端口 |
| `FRIDGE_DATA` | ./data | 数据目录 |
| `FRIDGE_TICK` | 5 | 后台任务间隔（秒） |
| `FRIDGE_APPEAL_SECONDS` | 172800 | 申诉期时长（秒） |
| `FRIDGE_PENDING_TTL` | 120 | 暂存待确认超时（秒） |
