# 写字楼公共冰箱格位与过期清理系统

楼层冰箱登记、层架格位、租户部门、物品标签、存放/保留期限、温度记录、临时停机、
清理批次、认领申诉与卫生检查的一体化管理。**仅依赖 Python 3 标准库**，SQLite 持久化，
本地目录存放标签与清理照片。

## 一条命令启动

```bash
./run.sh --reset        # 首次启动：生成示例数据（无标签 / 停机 / 申诉样例）
# 之后访问 http://localhost:8000 （自定义端口：PORT=8123 ./run.sh）
```

之后直接 `./run.sh` 即可保留数据启动；运行测试：

```bash
python3 -m unittest discover -s tests -v
```

## 角色与权限

| 角色 | 权限 |
|---|---|
| 租户员工 | 贴签、三步快速存放、撤销本人存放、对本部门物品申诉/认领 |
| 租户管理员 | 员工权限 + **确认争议**（维持处置 / 返还格位，仅限本部门） |
| 保洁 | **只能执行清理**（拍照入临时保留区）、登记巡检异常与卫生检查；不能存放、不能关单、不能停机 |
| 物业 | 临时停机、批量迁移、异常关闭；不能替其他部门复核争议 |

## 核心业务规则

- **一格里一件**：一个格位只允许一件有效物品；并发存放仅首个成功（第二人被
  `cell_holding` / `cell_taken` 拦截）。
- **关门确认**：贴签 → 选空余格位（门磁 OPEN）→ 关门确认，30 秒内完成，否则本次失效；
  关门完成前格位不计占用。完成后可一键**撤销**，释放格位并作废标签。
- **到期清理**：保留期默认 48h，到点由进程内任务送入「到期队列」；保洁勾选后
  **拍照**放入临时保留区，生成清理批次，进入 **24h 申诉期**，期满自动处置。
- **停机迁移**：仅物业操作。未到期物品批量迁至运行中冰箱的空余格位并**保留原标签**；
  已到期物品转清理队列；现场清点缺件登记「迁移缺件」异常。
- **租户隔离**：标签绑定部门，不能跨部门使用、申诉、认领；租户管理员只能复核本部门争议。

七类异常分别处理：无标签物品、占错格位、液体泄漏、重复扫码（存放时拦截）、
温度超限（模拟适配器自动开单）、迁移缺件、清理申诉（复核闭环）。

## 七个交付页

1. **冰箱格位图** — 按层架比例绘制（`width_ratio`），格内只显示部门简称与日期；
   在存 / 到期 / 开门待确认三态用薄荷绿、红、琥珀虚线区分，停机冰箱有遮罩。
2. **快速存放** — 贴签 → 选格 → 关门确认三步，完成卡片提供明确的撤销反馈。
3. **到期队列** — 收件箱式列表，保洁拍照批量清理。
4. **清理批次** — 批次表可行内展开清理照片。
5. **停机迁移** — 先出迁移计划预览（原格位 → 目标格位、到期转清理），物业再执行。
6. **温度记录** — 单系列折线（薄荷绿）+ 8℃ 上限虚线 + 超限红点，悬浮十字提示。
7. **申诉复核** — 临时保留区收件箱，行内展开清理照片，认领/申诉/管理员复核。
8. **卫生巡检** — 六类异常 Tab + 巡检登记 + 卫生评分（<80 自动开单）。

## 样式

办公白 `#F7F9F8` / 薄荷绿 `#3FBF9B` / 深灰 `#2E3A38`，辅以琥珀（到期/开门）与砖红（超限）。

## 数据与目录

```
fridge/
  app.py          # 领域模型 + SQLite 事件存储（item_events 事件溯源）+ 模拟适配器
  seed_data.py    # 示例主数据与样例场景
  server.py       # HTTP API + 静态页 + 进程内定时任务（10s 轮询）
  web/index.html  # 单页应用（无外部依赖）
  data/           # 运行后生成：fridge.db、media/labels/*.svg、media/*.svg（清理/取证照片）
tests/test_fridge.py  # 格位竞争、标签失效、迁移完整、期限边界、租户隔离、角色矩阵等 20 例
```

`item_events` 记录每件物品的完整生命周期：stored → expired → removed →
appealed/restored/claimed/disposed（另有 relocated、undone、migration_missing、
found_unlabeled 等）。媒体为本地生成的 SVG「照片」，无需网络或图片库。

## 示例场景（`--reset` 后自带）

F3 冰箱处于停机状态（两件未到期待迁移、一件到期转清理）；F1 有 3 件到期物品在队列；
一件已申诉物品等待市场部管理员复核、一件未申诉；另有无标签便当、液体泄漏、占错格位、
F2 温度超限（24h 逐时采样含 6 个超限点）、一次不达标卫生检查。顶栏可切换 8 名示例人员，
按角色体验不同权限。
